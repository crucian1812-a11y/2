# ⚽ FIFA World Cup 2026 — фан-сайт

Многостраничный статический сайт о чемпионате мира по футболу 2026
(США · Канада · Мексика). Чистые HTML + CSS + JavaScript — без сборки,
без внешних зависимостей и без бэкенда.

## Структура

```
docs/
├── index.html        — главная: обзор турнира, счётчик до финала 19 июля
├── bracket.html      — сетка плей-офф (1/8 → 1/4 → 1/2 → финал + матч за 3-е место)
├── quizzes.html      — квизы: выбор уровня и сама игра
├── penalty.html      — мини-игра «Пробей пенальти»
├── assets/
│   ├── styles.css    — общие стили всех страниц
│   ├── nav.js        — общая шапка/навигация и подвал
│   └── data.js       — ВСЕ редактируемые данные (матчи, команды, вопросы)
└── README.md         — этот файл
```

## Как включить GitHub Pages

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. Выберите ветку с сайтом и папку **`/docs`** (если сайт лежит в `docs/`,
   как сейчас) или **`/ (root)`** (если перенесёте файлы в корень ветки).
4. Нажмите **Save** — через минуту-другую сайт появится по адресу
   `https://<логин>.github.io/<репозиторий>/`.

### Про относительные ссылки

Сайт публикуется в подпапке репозитория
(`…github.io/<репозиторий>/…`), поэтому все ссылки между страницами и на
ресурсы — **относительные** (`./bracket.html`, `./assets/styles.css`).
Так сайт работает и локально (просто откройте `index.html` в браузере),
и на GitHub Pages без каких-либо правок. Не заменяйте их на абсолютные
пути вида `/bracket.html` — на Pages они сломаются.

## Где что редактировать (`assets/data.js`)

Все данные собраны в одном файле `assets/data.js` — страницы читают его
автоматически.

### Результаты матчей и пары плей-офф — `WC.bracket`

⚠️ **Счета турнира меняются — обновляйте их вручную.**

* Вписать результат: замените `score: null` на `score: [2, 1]`
  (голы хозяев, голы гостей). Победитель автоматически «переедет»
  в следующий раунд на странице плей-офф.
* Ничья в основное время: оставьте равный `score` и добавьте серию
  пенальти — `pens: [4, 3]`.
* Пары следующих раундов задаются ссылками
  `{ winnerOf: "R16-1" }` / `{ loserOf: "SF-1" }` — их менять не нужно,
  сетка строится по ним сама. Дата и стадион — свободный текст в полях
  `date` и `venue`.

### Вопросы квизов — `WC.quizzes`

Три уровня: `easy`, `medium`, `hard`. Каждый вопрос — объект:

```js
{
  q: "Текст вопроса?",
  options: ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
  correct: 1,            // индекс правильного варианта, счёт с нуля!
  note: "Пояснение…"     // необязательно, показывается после ответа
}
```

Добавляйте и удаляйте вопросы прямо в массивах `questions` —
прогресс-бар и подсчёт очков подстроятся автоматически.

### Команды и список для игры в пенальти

* `WC.teams` — справочник команд: код → название + эмодзи-флаг.
* `WC.penaltyTeams` — какие команды доступны в игре «Пробей пенальти»
  (массив кодов из `WC.teams`).

## Локальный просмотр

Ничего собирать не нужно: откройте `docs/index.html` в браузере
или поднимите любой статический сервер, например:

```bash
cd docs && python3 -m http.server 8000
# → http://localhost:8000
```
