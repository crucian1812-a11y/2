# 🗓️ Семейный календарь

Общий календарь семьи: события, дни рождения, кружки и планы — на одной
странице. Статический сайт на GitHub Pages, данные — в бесплатном
[Supabase](https://supabase.com) (Postgres). Без сборщиков и фреймворков:
только HTML, CSS и ванильный JS, `supabase-js` подключается из CDN.

- **Смотреть могут все** — гости видят календарь в режиме «только чтение».
- **Редактировать — только свои**: вход по magic link на email, без паролей.
- **Realtime**: событие, добавленное с одного устройства, тут же появляется
  на всех открытых вкладках.
- Повторяющиеся события (еженедельно / ежемесячно / ежегодно), фильтр по
  членам семьи, ближайшие события, тёмная тема.

> Про другой контент этого репозитория: конспекты YouTube — в
> [YTBRAIN.md](YTBRAIN.md), прежняя корневая страница переехала в
> [novgorod.html](novgorod.html).

## Настройка с нуля

### 1. Создать проект на Supabase

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатного
   тарифа достаточно).
2. **New project** → придумайте имя и пароль БД, выберите ближайший регион.
3. Дождитесь, пока проект поднимется (~2 минуты).

### 2. Выполнить schema.sql

1. В панели проекта откройте **SQL Editor**.
2. Скопируйте содержимое [`supabase/schema.sql`](supabase/schema.sql)
   целиком и нажмите **Run**.

Скрипт создаст таблицы `family_members` и `events`, включит RLS-политики,
выдаст гранты для REST API, включит realtime-публикацию и добавит
демо-данные (их можно удалить в **Table Editor**).

### 3. Вписать URL и anon key

1. В панели Supabase: **Project Settings → API**. Скопируйте
   **Project URL** и **anon public** key.
2. Вставьте их в [`assets/config.js`](assets/config.js):

   ```js
   export const SUPABASE_URL = 'https://xxxxx.supabase.co';
   export const SUPABASE_ANON_KEY = 'eyJhbGciOi...';
   ```

3. Те же значения добавьте в секреты репозитория для keepalive-workflow:
   **Settings → Secrets and variables → Actions → New repository secret**:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`

> **Это безопасно?** Да. Anon key — публичный по замыслу: он попадает в
> браузер каждого посетителя в любом Supabase-проекте. Он даёт только те
> права, которые разрешены политиками Row Level Security: у нас — чтение
> для всех, запись только для залогиненных. Данные защищает не секретность
> ключа, а RLS-политики в базе.

### 4. Включить вход по email (magic link)

1. В панели Supabase: **Authentication → Sign In / Up** — провайдер
   **Email** должен быть включён (он включён по умолчанию).
2. В **Authentication → URL Configuration** добавьте адрес вашего сайта
   (`https://<username>.github.io/<repo>/`) в **Site URL** и
   **Redirect URLs** — иначе ссылка из письма приведёт на localhost.
3. Приглашать «своих» отдельно не нужно: любой, кто войдёт по magic link,
   получает право записи. Если хотите ограничить круг — отключите
   регистрации (**Authentication → Sign In / Up → Allow new users to sign
   up → off**) после того, как все члены семьи войдут первый раз.

### 5. Включить GitHub Pages

1. **Settings → Pages → Build and deployment → Source** →
   выберите **GitHub Actions**.
2. Запушьте в `main` — workflow `deploy.yml` соберёт и опубликует сайт.
   Адрес появится в **Settings → Pages**.

### 6. Как добавить члена семьи и событие

**Член семьи** — через панель Supabase (**Table Editor → family_members →
Insert row**): имя, hex-цвет (например `#2f6f8f`) и эмодзи. Цвет станет
акцентом всех событий этого человека в интерфейсе.

**Событие** — прямо на сайте:

1. Нажмите **Войти**, введите email, откройте ссылку из письма.
2. Нажмите **+ Событие** (или кликните нужный день → «Добавить событие»).
3. Заполните название, дату, время, выберите члена семьи, при
   необходимости — заметку и тип повтора. **Сохранить** — событие сразу
   появится у всех, у кого открыт календарь.

Редактирование и удаление — по клику на день, в списке событий этого дня.

## Как устроены повторяющиеся события

В базе хранится одна строка с полем `recurring`
(`none | weekly | monthly | yearly`). При рендере месяца повторы
разворачиваются на лету: «каждый месяц 31-го» пропускает короткие месяцы,
«29 февраля ежегодно» показывается только в високосные годы.

## Keepalive

Бесплатный проект Supabase засыпает после ~недели без запросов.
Workflow [`keepalive.yml`](.github/workflows/keepalive.yml) раз в 3 дня
делает лёгкий GET-запрос к REST API (ключи берёт из GitHub Secrets),
и проект остаётся активным.

## Локальная разработка

ES-модули не работают с `file://`, нужен любой статический сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```
